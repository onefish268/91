# YSS 可直接覆盖版（V159）

这个目录是**纯新增**内容，不影响本仓库原有的任何文件。

## 内容
- `YSS_V159_可直接覆盖版.zip` —— 打包好的模型包
- `gfx/` —— 与 zip 相同内容的解包版（方便在 GitHub 上直接查看文件）
- `安装说明.txt` —— 文件清单与 md5

## 用法
把本目录里的 `gfx/` 复制到
`...\Hearts of Iron IV\mod\YSS_fix\`
覆盖同名文件即可（这是给 YSS_fix 模组用的替换模型）。

## 与原仓库模型的关系
本仓库原有的 `gfx/models/units/YSS_models/SOV_infantry.mesh` 与
`gfx/entities/YSS_model.gfx` **未被修改**；本目录是独立的一套可直接覆盖版。
